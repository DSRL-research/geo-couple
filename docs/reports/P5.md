## 5. Concluzii

1. **E6, transfer pe layout:** G1 și A1 bat B0 și S0 pe C (C proprii G1 4.6%, A1 6.0%, S0 14.0%, B0 13.4%; C mutuale G1 7.3%, A1 8.4%, S0 13.6%, B0 13.0%); L rămâne la nivelul B0 pentru toate (L proprii ~0.12%). B5 nu se transferă (C mutuale 101%).
2. **Lanțuri lungi (≥ 10 primitive):** A1 extrapolează cel mai bine: C mutuale 6.4% (S0 22.5%, G1 28.1%), iar coada se îmbunătățește: p95 C mutuale 10.8% (S0 25.3%, G1 34.2%, B0 26.6%). Pe celulele scurte coada rămâne ~28% pentru toate variantele.
3. **E4:** la buget mic, etichetele coarse (≈ 5% din costul unei simulări fine) reduc eroarea cu un ordin de mărime; la buget mare, varianta doar fine câștigă (corecția GP are un prag de zgomot de ~0,1%).
4. **E5:** costul FEM crește supraliniar cu numărul de tetraedre, inferența modelelor e independentă de mesh (sub-milisecundă / celulă pentru S0, ~1 ms pentru A1).
